# Portfolio — بورتفوليو صانعة محتوى AI

موقع بورتفوليو بستايل أسود × بينك (زي البريزنتيشن)، بالعربي والإنجليزي (زرار EN / ع)، وبيشتغل على الموبايل والكمبيوتر.

الشرايح: PORTFOLIO · ABOUT ME · SKILLS · CASE fashion · food · furniture · cartoon · series · & more · CONTACT ME

## إزاي تعدّلي المحتوى
كل حاجة في ملف **`data.js`**:
- `profile`: اسمك (بالعربي والإنجليزي)، النبذة، الأدوات.
- `skills`: المهارات.
- `cases`: كل مجال شغل. ضيفي الصور والفيديوهات في `media`:
  ```js
  media: [
    { type: "image", src: "images/fashion-1.jpg" },
    { type: "video", src: "images/fashion-reel.mp4" },
  ]
  ```
  أول ٣ بيظهروا على الشريحة، والباقي بيظهر لما حد يدوس عليها.
- `contact`: الإيميل وروابط إنستجرام / تيك توك / واتساب / بيهانس. كل رابط بيتعمله QR code تلقائي، والرابط الفاضي مش بيظهر.

## الصور
حطي الصور والفيديوهات في فولدر `images/`. صورتك موجودة جاهزة: `images/me.webp`.
الفيديوهات: يفضل MP4 وحجمها صغير (أقل من ~10MB) عشان الموقع يفتح بسرعة.

## التشغيل والنشر
افتحي `index.html` في المتصفح. للنشر مجانًا: GitHub Pages (Settings ← Pages ← Branch).
الخطوط ومكتبة الـ QR موجودين جوه الموقع نفسه (`fonts/`, `vendor/`).
